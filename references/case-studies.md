# Case Studies — *why* top apps feel premium

Knowing Material 3 and HIG tells you the *rules*. This file tells you the *taste* — the specific decisions that make Linear feel precise, Revolut feel luxe, Telegram feel fast. When a user says "make it like X", or you just want a premium reference point, pull the closest app's DNA and apply its hierarchy / density / radius / shadow / motion / color signature.

**How to use:** pick the app whose *feeling* matches the goal, copy its signature, and obey its "AI pitfalls" (the mistakes that break that specific look). Don't copy a brand's exact colors — copy its *system*.

Each card uses the same fields so they're directly comparable.

---

## Linear — *precision / pro tool*
- **Hierarchy:** title dominant, secondary muted (~60%), tertiary nearly hidden (~38%). Ruthless.
- **Density:** high. Tight rows, little wasted space, information-dense without feeling cramped.
- **Radius:** 8–12, consistent.
- **Shadows:** almost none. Separation via hairline borders + subtle background tiers.
- **Color:** monochrome neutral base + a single restrained accent (indigo/violet). Tinted grays, off-black surfaces.
- **Type:** Inter-style; tight tracking on headings; medium/semibold weights; crisp.
- **Motion:** fast, 160–220ms, ease-out; instant-feeling, no bounce.
- **AI pitfalls to avoid:** too many cards, too much spacing, too many colors, soft shadows everywhere.
- **Signature:** *precision.* Every pixel deliberate; restraint is the brand.

## Revolut — *luxury fintech*
- **Hierarchy:** balance/number is the hero; everything orbits it. Big, confident numerics.
- **Density:** compact-premium. Dense but with intentional breathing room around the hero.
- **Radius:** 12–20; cards feel like physical cards.
- **Shadows:** soft, layered, low-opacity — depth without harshness.
- **Color:** deep dark surfaces, vivid but controlled accent (electric blue/purple), gradient *as accent* on cards/CTAs, metallic/gradient card art.
- **Type:** strong, slightly condensed; **tabular figures** for money (non-negotiable).
- **Motion:** smooth springs, numeric roll on balances, satisfying card/sheet transitions, haptics on actions.
- **AI pitfalls:** flat gray cards, jittering non-tabular numbers, loud rainbow gradients, no depth.
- **Signature:** *premium money.* Confident numerals + tasteful depth + motion polish.

## Telegram — *speed / clarity*
- **Hierarchy:** content-first; chrome minimal. The message is everything.
- **Density:** very dense (chat list, messages) yet legible — tight vertical rhythm.
- **Radius:** ~18 bubbles (smaller corner on the tail side); ~10 rows.
- **Shadows:** minimal; flat surfaces, thin separators.
- **Color:** neutral surfaces, one accent (blue), accent bubble for outgoing; great dark theme.
- **Type:** system font, compact line-height, clear secondary metadata (time/ticks muted).
- **Motion:** instant + buttery; fast list, smooth keyboard, snappy transitions, no lag ever.
- **AI pitfalls:** over-padded chat rows, oversized bubbles, decorative shadows, slow animations.
- **Signature:** *fast.* Density + zero jank = feels instantaneous.

## Airbnb — *warm / editorial*
- **Hierarchy:** big imagery leads; title + price clear; supporting muted.
- **Density:** medium. Generous but not empty; photo-driven cards.
- **Radius:** 12–16; large rounded image cards.
- **Shadows:** very subtle; relies on imagery + spacing for structure.
- **Color:** warm neutrals, brand coral accent used sparingly, lots of white space, photography is the color.
- **Type:** friendly, rounded-ish, comfortable line-height; approachable not corporate.
- **Motion:** gentle, smooth scroll, soft transitions, tasteful image parallax.
- **AI pitfalls:** tiny images, cramped photo cards, coral everywhere, cold/corporate spacing.
- **Signature:** *warm trust.* Editorial imagery + breathing room.

## Notion — *calm / content*
- **Hierarchy:** text-first, gentle; emphasis through weight + spacing, not color.
- **Density:** medium-low; airy, document-like.
- **Radius:** small (4–8); understated.
- **Shadows:** almost none; flat, paper-like.
- **Color:** near-monochrome, muted; sparse accent; lots of neutral.
- **Type:** clean, readable, generous line-height; content is king.
- **Motion:** subtle, calm; nothing flashy.
- **AI pitfalls:** over-decorating, adding color/cards where plain text + space is right.
- **Signature:** *calm clarity.* Quiet, content-forward.

## Stripe — *trust / engineering polish*
- **Hierarchy:** structured, grid-precise; clear sections; data legible.
- **Density:** medium-high; organized, never chaotic.
- **Radius:** 8–12.
- **Shadows:** subtle, refined; crisp borders.
- **Color:** restrained, professional; indigo accent; tasteful gradients on hero/brand surfaces only.
- **Type:** precise, technical clarity; excellent numerics/tables.
- **Motion:** refined, purposeful; smooth, never gratuitous.
- **AI pitfalls:** messy alignment, inconsistent spacing, gradient overuse.
- **Signature:** *engineered trust.* Grid precision + restraint.

## Arc Browser — *playful-premium / expressive*
- **Hierarchy:** bold, expressive, but controlled; strong focal moments.
- **Density:** medium; spacious with personality.
- **Radius:** larger, continuous (16–24); soft, friendly.
- **Shadows:** soft + colorful tints; gradient backgrounds done tastefully.
- **Color:** vivid gradients as identity, but balanced with neutral; expressive yet not garish.
- **Type:** confident, modern, characterful.
- **Motion:** delightful, springy, characterful micro-interactions, satisfying transitions.
- **AI pitfalls:** copying the gradients without the restraint → garish; motion overload.
- **Signature:** *expressive premium.* Personality with discipline.

## Coinbase — *clean crypto / data confidence*
- **Hierarchy:** numbers + charts lead; clean, trustworthy.
- **Density:** medium; clear lists, prominent values.
- **Radius:** 12–16.
- **Shadows:** subtle.
- **Color:** clean neutral base, blue accent, green/red strictly for gain/loss only.
- **Type:** strong numerics, **tabular figures**; clear data.
- **Motion:** smooth chart animation, numeric transitions, calm.
- **AI pitfalls:** red/green used decoratively, cluttered charts, jittery numbers.
- **Signature:** *confident clarity* for money/data.

## Duolingo — *fun / gamified delight*
- **Hierarchy:** one clear action per screen; big friendly focal elements.
- **Density:** low; spacious, focused, one-thing-at-a-time.
- **Radius:** large, rounded, chunky (16–24); soft buttons with a 3D "bottom" press.
- **Shadows:** chunky/solid offset (button depth), playful.
- **Color:** bright, saturated, energetic — but per-screen disciplined; mascot color identity.
- **Type:** rounded, friendly, bold.
- **Motion:** bouncy springs, celebratory moments, generous haptics, character animation.
- **AI pitfalls:** applying this playfulness to a serious app; too many bright colors at once.
- **Signature:** *joyful focus.* Delight + one clear action.

## Picking a reference (quick map)
- Pro tool / dashboard / productivity → **Linear / Stripe / Notion**
- Fintech / banking / crypto → **Revolut / Coinbase / Stripe**
- Messaging / social / fast lists → **Telegram**
- Travel / marketplace / lifestyle → **Airbnb**
- Consumer / playful / education → **Duolingo / Arc**

Then apply that app's hierarchy + density + radius + shadow + motion + color signature, and respect its AI-pitfall list. Combine with `visual-hierarchy.md`, `screen-density.md`, and `premium-polish.md`.
